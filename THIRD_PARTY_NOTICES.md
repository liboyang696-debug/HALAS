# Third-party notices

## ExplainableXR

`UnityProject/ExplainableXR` contains an adapted version of the ExplainableXR logging package by Yoonsang Kim and contributors. The original MIT license is retained in that directory. HALAS adds edge transport and integrates action-evidence AoI behavior processing with the package.

Related work: *Explainable XR: Understanding User Behaviors of XR Environments using LLM-assisted Analytics Framework*, Yoonsang Kim et al., IEEE TVCG, 2025.

The `Whisper.Utils` microphone utilities in that package retain their source headers, including their attribution to whisper.unity contributors.

## Three.js

The Web console uses Three.js and its GLTFLoader/OrbitControls scripts. Their MIT license is retained in `Visual Analytics Interface/webApp/vendor/three/LICENSE`.

Original project: https://github.com/mrdoob/three.js

## Device SDKs and Python libraries

Unity packages, the PICO device SDK and Python dependencies are obtained separately and retain their respective licenses. Their model weights and SDK distributions are not part of this source release.
